提示词的创作在左边的对话框里完成：读参考图分析风格、组织措辞、最小化修改，由对话里的 agent 按随包 skill 执行； 本面板负责机械环节——校验结构、冻结比对、预设存取、出图执行与历史。下面四张卡片选一条路径，点按钮就会带着填好的指令开一个新对话。
路径 A+图

参考图反推

给一张参考图（本地图片绝对路径），agent 直接读图按四维度提取风格特征（角色/场景/画风/构图镜头），反推出结构化提示词；出图时原图自动传回作风格参考。

路径 A

一句话生成

没有参考图，直接一句话描述想要的画面，agent 按 26 字段规范产出完整结构化 JSON 提示词。

路径 B

最小化修改

拿一份已有 JSON 说「改成 XX」，agent 只动你要求的字段、其余逐字冻结；改完自动跑 ips_diff 冻结比对，画风不漂移。先在「提示词编辑」页粘好原 JSON 或从预设库加载。

路径 C

提示词出图

提示词就绪后在本面板直接出图：GPT-Image（默认）或 Nano Banana 双家族任选，参考图自动传回。源自参考图的提示词，出图时必须把原图传回（铁律）。

前提：提示词 JSON 已在「出图」页（编辑器会自动带过去），且插件设置配好 apizApiKey 或本机 apiz CLI 已登录。

新来的？先去「预设库」挑一套贴近的预设（Q版/三国/宋代/线稿漫画/讽刺漫画/中秋星野等 9 套）加载进编辑器看看 JSON 长什么样，再回这里选路径。
内置 9 套预设（只读）+ 用户自存预设。点「加载」把预设读进编辑器，生成新提示词时可以作风格基准改写。「仅角色」等部分结构预设走部分模式校验。
